Excel Extraction Engine v2
==========================

هذه النسخة تطور محرك استخراج Excel من مجرد قراءة صفوف إلى محرك يفهم بنية ملفات الفواتير التجارية.

المزايا الرئيسية:
- اكتشاف ورقة وجدول الفاتورة وصف Header تلقائيًا.
- فهم Headers العربية والإنجليزية والمركبة مثل: الكمية / Qty.
- قاموس دلالي للحقول مع قواعد سياقية تمنع خلط VAT مع السعر أو الإجمالي مع الصافي.
- استخراج بيانات رأس الفاتورة: المورد، رقم الفاتورة، التاريخ، الرقم الضريبي واسم العميل عند توفرها.
- اكتشاف أعمدة الكود، الاسم، الكمية، الوحدة، السعر، الصافي، الضريبة والإجمالي.
- تحليل محتوى الأعمدة وليس اسم العمود فقط.
- تصنيف صفوف الفاتورة واستبعاد الإجماليات والملاحظات والتذييل والبيانات غير الصنفية.
- تحقق حسابي للعلاقة بين الكمية والسعر والصافي والضريبة والإجمالي.
- عند غياب بعض القيم المالية، يمكن حسابها في النموذج الموحد مع توضيح أنها محسوبة.
- درجات ثقة وتشخيص قابل للمراجعة.
- دعم قوالب الموردين المحفوظة، مع استخدام القالب فقط عند تطابق بصمة Header.
- لا يوجد تخمين حر عند عدم التعرف على Header؛ الملف غير المعروف لا يُحوّل إلى بيانات مالية خاطئة.
- الناتج يبقى متوافقًا مع محرك المطابقة الحالي.

قاعدة مهمة:
عدم استخراج البيانات أفضل من استخراج بيانات خاطئة. أي ملف غير واضح يجب أن يدخل للمراجعة بدل التخمين.

الاختبارات:
- اختبار Excel أساسي.
- اختبار فاتورة شركة ثمار الغدا الفعلية.
- اختبار استبعاد صفوف التذييل.
- اختبار منع التخمين في ملف مجهول Header.

v2.55 — إصلاح زر اعتماد الاقتراح وإعادة اختبار تغيير الصنف
- اعتماد الاقتراح أو الربط داخل شاشة الفاتورة يغيّر السطر الحالي فورًا، ولا يثبت أي تعلم في قاعدة البيانات قبل نجاح حفظ الفاتورة.
- عند حفظ الفاتورة/تحديث فاتورة المراجعة، تُثبت آخر قرارات المستخدم فقط داخل نفس المعاملة؛ الفشل أو الإلغاء لا ينشئ تعلمًا جديدًا.
- كود المورد يبقى دليلًا أساسيًا عند توفره، مع تطبيع آمن للكود واكتشاف لاحتمال التصاق رقم تسلسل السطر مثل 024097(1) عندما يطابق رقم السطر.
- الاقتراحات المبنية على الاسم والخصائص والسعر تبقى اقتراحات قابلة للمراجعة ولا تُفرض تلقائيًا عند وجود تعارض في كود المورد.
- أضيفت إدارة للروابط والأسماء البديلة: تعديل، تعطيل، إعادة تفعيل، وسجل تغييرات التعلم والتعارضات.
- لا توجد تغييرات مقصودة على دورة تصدير الأصناف إلى المتكامل بلس أو دورة الفواتير المعتمدة خارج ما يلزم لإدارة التعلم الجديدة.
